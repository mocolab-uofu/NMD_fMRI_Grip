* Source
Github: [[https://github.com/mandymejia/BayesfMRI][Bayes fMRI]]

* Install prerequisites
#+begin_src bash
# * Install prerequisites for compiling BayesfMRI in R

# ** For 'sf'
sudo apt-get install -y \
     libudunits2-dev \
     libgdal-dev \
     libgeos-dev \
     libproj-dev

# ** For 'excursions'
sudo apt-get install -y libgsl-dev
#+end_src

* Install BayesfMRI via CRAN
This took about 5 minutes.
#+begin_src R
## * Install packages
# sf and excursions are prerquisites for BayesfMRI
install.packages(c("sf", "excursions", "BayesfMRI", "hrf"))
#+end_src

Note that for the BayesGLM2 (the second level), we need version 12. While writing this, version 11 is on CRAN, so with the above method, you won't get the version 12, but version 11. Should be fine for the first level analysis though.

* Install INLA
#+begin_src R
## * Install INLA
install.packages("INLA",
                 repos = c(getOption("repos"),
                           INLA = "https://inla.r-inla-download.org/R/stable"),
                 dep = FALSE
                 )

## * Install INLA binaries
INLA::inla.binary.install()
#+end_src
